PersonalS3 gives you private, S3-compatible storage. You upload files, share them, and stream media — all from a hosted account on this instance.

There are three ways to do every common thing:

- **Dashboard** — the website you're reading this in
- **`ps3` CLI** — a binary you install once and call from your terminal
- **HTTP API** — direct calls from your own scripts or apps

This documentation walks through each one. Skim the section that matches how you want to work, or read straight through if it's your first day.

## Where to start

- **First time here?** Start with [Account & access](/account/requesting-an-account/) → request an account, then install the CLI.
- **Got an account?** Jump to [Uploading files](/uploading/choosing-an-upload-method/).
- **Building an integration?** Read [Uploading via the HTTP API](/uploading/single-put-api/) and [API keys](/account/api-keys/).

## What this isn't

You're reading user documentation. If you're trying to run your own PersonalS3 instance from source, you want the project's repo README, not this site.
