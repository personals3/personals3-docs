---
title: Requesting an account
---

PersonalS3 accounts are administrator-approved — there's no self-signup link that creates an account immediately. The flow is short:

1. **You submit a request** from the sign-in page (the "Request access" link).
2. **The administrator reviews it.** They get an email when your request lands.
3. **You get an email back** — approval includes a verification code that you use to set your first password. Denial includes a brief note.

Approval usually arrives within a day or two. Every approved account starts with **100 MB of free storage**. Need more later? See [Asking for more space](../quotas/need-more-space).

## What to put in the form

The form asks for three things:

| Field | What to write |
|---|---|
| **Email** | The address you want to sign in with. Notifications and password resets go here too. |
| **Name** | Your real name or the team name you'll be using. |
| **Reason (optional)** | A sentence about why you need access. Helps the admin decide quickly. |

We don't ask for any payment details — billing isn't part of this version.

## After approval

You'll receive **two emails**:

1. *"Your access was approved"* — confirms the email, quota, and dashboard URL.
2. *"Verify your email"* — contains a 6-digit code (valid for 24 hours).

Click "**Set your password**" on the sign-in page, paste the code, choose a password (8+ characters), and you're in.

## I never got the email

- Check spam.
- Wait 10 minutes — admin notification mail is queued.
- Use the "[Forgot password](../account/logging-in#i-forgot-my-password)" flow with the same email — if the admin approved you, that flow also works to set a password.
- If still nothing, contact the administrator of this instance directly.
